# Step 1.3.2 — Header Detection

## 1. Objective

The purpose of Header Detection is to identify the row in a candidate SOV sheet that most likely represents the actual column headers.

We cannot assume that the first row of an Excel sheet is the header because real SOV workbooks may contain:

- Blank rows
- Company/client information
- Report titles
- Metadata
- Notes
- Multiple header rows
- Merged cells
- Grouped column headings

Therefore, the system will inspect the beginning of each sheet and determine the most likely header row using deterministic evidence.

---

## 2. Input

The Header Detection component receives:

- Sheet name
- Raw pandas DataFrame
- Sheet profile generated by the Sheet Profiler

The raw DataFrame must remain unchanged.

We will initially inspect the first 30 rows of the sheet.
