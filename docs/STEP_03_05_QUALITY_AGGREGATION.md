# Step 3.5 — Quality Issue Aggregation

## Objective

The Quality Aggregator converts the individual quality issues generated by
Agent 3's deterministic validation layer into a structured quality report.

The aggregator does not modify the source DataFrame and does not automatically
correct any detected issue.

---

## Why This Step Is Needed

The deterministic validation layer can generate many individual
`QualityIssue` objects.

For example:

- missing values
- invalid types
- negative monetary values
- invalid categories
- invalid ranges
- future Year Built values
- duplicate references
- semantic validation issues
- statistical anomalies

Sending these individual issues directly to later reasoning components makes
the state difficult to interpret.

The aggregator provides a structured summary.

---
